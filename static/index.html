☢ Emergency Clear

Terminates every running instance, deletes every orphan volume, cancels every spot request, and empties every S3 prefix that this app has tagged Application=infinite-streaming-encoder-app. Does not touch anything without that tag.

Not cleared here: the pre-baked worker AMI (if you ran make bake-ami). It's an AMI + EBS snapshot, not a running resource, so this button leaves it alone. It costs ~$1.50/mo in snapshot storage while it exists. Remove it from the command line with: 

make unbake-ami   # just the AMI + its snapshot, then re-run: make infra-apply
make clear-costs  # this button's sweep AND the AMI, in one command

Or by hand: aws ec2 deregister-image --image-id <ami> then aws ec2 delete-snapshot --snapshot-id <snap> (find them with aws ec2 describe-images --owners self --filters Name=tag:Name,Values=infinite-streaming-encoder-worker).
